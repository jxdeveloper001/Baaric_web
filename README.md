# Baaric — শিশুর কোমল যত্নের প্রাকৃতিক তেল

Premium Bengali-first single-product landing page for Baaric baby oils.
Next.js 16.4.6 + TypeScript + Tailwind v4. No backend, no env vars.

- 3 oils, 4 variants (Massage Oil 50 ml / 150 ml, Hair Oil 150 ml, Coconut Oil 200 ml) — sizes read off the bottle labels.
- Product photos are crops of the two original images supplied by the user; bottle labels are unchanged.
- No price / delivery / COD claim anywhere — none was supplied. Order form collects a request; price + delivery are confirmed on the call.
- Reviews are SAMPLES (labelled on the page). Contact details not yet supplied.

Run: `npm run dev` · Build: `npm run build`
